Batting Pressure Reliability Index (BPRI)

Scale 0–100

Grades batters on scoring velocity, over-by-over par expectation outperformance, dismissal resistance, clutch delta uplift, and inning consistency.

BPRI = 100 * [ RawScore_bat * w_sample + 0.50 * (1 - w_sample) ]

w_sample = N / (N + 100) (Empirical Bayes Shrinkage)

Bowling Pressure Reliability Index (BoPRI)

Scale 0–100

Grades bowlers on phase-adjusted run containment, economy par differential, strike rate, dot ball generation, and spell consistency.

BoPRI = 100 * [ RawScore_bowl * w_sample + 0.50 * (1 - w_sample) ]

w_sample = N / (N + 120) (Empirical Bayes Shrinkage)
